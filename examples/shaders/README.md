# Built-in shaders

Every `.wgsl` file here is built into tron. Shaders written for tron are
licensed like tron itself, MIT OR Apache-2.0. Ports of other authors' shaders
keep the license stated with the original, repeated at the top of each file.
The startup screen's Credits tab shows the same information.

CC BY-NC-SA shaders allow non-commercial use only, and changed versions must
use the same license. Shadertoy applies CC BY-NC-SA 3.0 to shaders whose
author stated no license. Shaders marked "None stated" come from sources that
give no license; they are included with credit to their authors, who can ask
for them to be removed.
